# 文字与表情素材整理

原始24张PNG按多语言操作提示16张、松鼠动作表情4张、小鸟表情4张分类，保留用户原PNG及画布/透明度，不修改像素。index.json包含尺寸、alpha范围与SHA256。

此目录位于正式地图工程外，避免一次导入并常驻24张大画布。部分原图带白底，后续使用时需单独处理，不能把整张白底当透明图。

本次仅启用“小鸟die了.png”：其画布1080×3240，实际透明图案区域Rect2(526,2593,83,65)，与当前小鸟原图的区域完全一致。原PNG另复制到正式工程assets/art/sky/expressions/bird_dead.png，运行时用AtlasTexture仅显示该区域。其他提示/表情暂不接入玩法。
