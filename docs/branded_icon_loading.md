# 原画图标与黑屏五豆加载

game_icon.png逐字节复制用户图标.png；ICO只做透明方形留白与Windows多尺寸编码，不改绘画。project.godot设置窗口图标与Windows原生图标，Windows导出预设使用同一ICO。导出验证EXE实际嵌入16/32/48/64/128/256尺寸图标。

Godot原生启动阶段禁用默认引擎标志，底色纯黑（此阶段不支持脚本动画）；新的轻量branded_boot主场景马上接既有settlement_return_home黑幕与五角色跳动，在后台加载主页，准备并绘制后先收豆子再揭幕。复用既有组件而非复制一套新动画。现有开始加载遮罩改纯黑，结束/死亡回主页已使用同一五豆黑屏流程，保留原角色与跳动次序。

检查：原生ANGLE启动黑底五角色截图、异步主页加载与揭幕；返回主页回归；Windows发布导出及EXE嵌入图标验证。引擎初始化最早瞬间为纯黑，初始化完成后才可能显示动态五豆。既有桌面旧ZIP不会自动改变，需要重新打包分发。

加载层级修正：旧黑幕layer80低于说明书94/设置与教程95，主页在黑幕下完成准备时图标会提前露出。统一黑幕升到1100、五豆1101，覆盖所有游戏界面及软件鼠标1000。只在完成加载/豆子退场后揭幕。原生启动检查在menu_ready且仍纯黑时，逐点采样说明书热区确认没有亮像素；返回主页层级与揭幕检查通过。
