# 丛林底部滑梯空气墙

BottomFunnel在原岸线两侧生成不可见实体斜坡，碰撞层32，与松鼠/地面一致。以真实JungleFloor顶部对齐，底部内沿x=180/1740，向上1450像素逐步展开至画面外x=-420/2340；最后160像素为竖直挡边并延伸到岸线下方。斜率约65度，超过角色站立坡度，落到侧面会顺碰撞法线滑向内侧，不形成可站立隐形平台；原上方软边界与藤蔓空间保留，不增加可见图画。岸线调整后同步重建。

松鼠摔死落差改为1500像素，仍实际落地才判死，抓藤/重生保护重置跟踪；沿侧墙滑行不把墙面当作落地来清零落差。致命落地仍先压扁回弹再掉落。

验证：正式场景中左右各从画面外高处实际自由下落，触碰斜坡后进入画面并落在原岸线；地面水平外走会被挡住，上方横向活动仍通畅。原生ANGLE和无窗口检查通过，1500落差及原死亡回弹/计数检查通过。
