# 丛林重生点与蜜蜂预警

未激活的丛林绑钻在左上侧显示原手绘白色双感叹号。松鼠附身且距离小于1100时可见，每2.8秒轻弹两下；死亡、过场、离远和激活立即隐藏。复用海底重生点的动画基类，仅独立覆盖丛林的显示条件；原绑藤、钻石和触碰范围不变。

近战及远程蜜蜂在WINDUP蓄力时显示同一原图的感叹号，沿用已有海底预警弹跳曲线并压入蜜蜂原0.55秒蓄力，白墨着色器去白底、留白色笔画。冲刺、发射结束、取消或被撞飞时收起，不调整攻击速度、间隔和伤害。

验证：蜜蜂蓄力/近战/远程/恢复预警及既有跟踪检查；丛林重生点原生显隐、激活、重试、短树枝流程；海底重生点回归均通过。原生截图检查提示位于钻石左上，不与右侧蜂巢混淆。
