# 海底Shift情境提示

海底移除局内OceanTutorial节点和3键强制录像入口；首页说明书仍保留原海底录像。丛林与天空局内录像不变。

OceanShiftReminder独立记录触手/细长鲨鱼两类学习状态。真实Stun.stunned记录触手错过，真实shark死亡记录鲨鱼错过；重试沿用同一节点记录。后续同类危险靠近时在鱼头上显示Shift；包含侧墙拍击、水母触手障碍、普通细长鲨与海面三鲨。无危险、离远、眩晕、技能冷却、死亡、出水或切关时不催按。实际瞬移在同类危险期间完成、0.3秒后仍能操作且未再受伤/死亡才记学会；随意在空处按或失败闪避不清掉提醒。

following_shift_prompt统一负责鱼/恶魔的图标、中心压扁回弹、按键反馈、短光线、屏幕变换和阻尼跟随。用原图的变换后包围框上沿作为头顶，鱼转向时图标仍在屏幕上方；不移动角色，不暂停关卡。

验证：原生ANGLE与无窗口实际打晕、恢复、瞬移、鲨鱼死亡、失败瞬移不误记；触手距离、两类记录独立、冷却隐藏、海面三鲨覆盖；反复3键无弹窗；地狱实际两次跳跃/前两只敌人提示及真实投叉击败回归；四章录播首帧同步与鱼瞬移全套检查通过。
