# 登顶后的向下回顾预览

入口：`正式地图工程/scenes/previews/settlement_descent.tscn`，在 Godot 打开后按 F6。

幽灵从云面弹出后，可移动和跳跃，同时播放约8.4秒光环奖励；奖励完成后从原云面褶皱钻回云里，再穿过云层向下移动，依次显示用户原画“恭喜你，成功进入天堂啦！”、“来瞅瞅你自己吧～”，以及地狱、海洋、森林、天空四个回放框。穿云快、文字和回放附近慢；缩放固定，镜头位置与速度连续。奖励结束后用 WASD 或四个方向键自由飞行，不再受重力、跳台或固定水平线限制。幽灵缩小至1.35倍，有柔和加速/松键减速、轻微倾斜、保面积形变及独立的光环跟随，保持无嘴。正常操作含光环的完整轮廓不能飞出屏幕；仅最终向上退场允许越界。

用户确认不修改“逃出／游出／穿越／冲破……次”的手写文字。数字来自新 ZIP 的 0～9，按透明边界取图，填在原横线上；显示的是对应关卡有效死亡次数，不把成功通关再加一次。长图只切取顶部六个 2048 像素区块，避免导入 52000 像素高的超限纹理，未重绘原图。

`RunRetrospective` 已挂在正式场景，监听统一 `died` 信号；死亡重试保留计数，重载/回首页开始新局清空。按当前宿主判别关卡；附身中仍计入离开的关卡。真实截图在正常可玩阶段以 8 fps 记录为 640×360 JPEG，每关环形保留最近 6 秒以及第一次失败前最多 6 秒，不记录死亡 UI 或转场。总样本上限四关各 96 帧，内存受限于 JPEG 内容大小。关闭 recording_enabled 可保留统计而停止录像。无录屏的 headless 模式只统计，不伪造画面。

结算调用 `set_history(level.get_node("RunRetrospective").snapshot())` 后，在原框内等比例播放对应真实截图。没有记录时框保持空白，数字为真实记录或默认 0，不把演示素材当成玩家回放。

当前仍为独立结尾预览，遵循先看效果再继续；尚未替换正式天空登顶流程，也未提前接入正式 100 橘子结局判定。独立启动时没有本局历史；需注入 snapshot 才显示录像和本局数字。

验证脚本：根目录 `tests/settlement_descent.gd`，覆盖四关分别计数、重试保留、快照独立、记录容量、附身归属、滚动单调与逐帧连续、奖励后控制、原横线数字及真实 JPEG 播放。测试素材不写入关卡。

## 自由飞行与结尾收束

`settlement_ghost_flight.gd` 用解析速度积分，30/60/120fps同一输入路径一致；角色不再每帧被跳跃公式拉回固定高度。屏幕位置与滚动的世界分离。云前景 CanvasLayer=2，高于幽灵的1；复用原画前三张切片，通过原画颜色分析生成的 cloud_edge.json 裁出云下沿，云层覆盖幽灵及光环，结算文字区域不被遮住。

回顾结束（默认50秒）后锁定退场方向，幽灵从当前位置平滑加速向上飞出；完整离屏才触发0.7秒黑幕。`settlement_return_home.gd` 挂在树根跨场景存活，黑屏右下角复用现有 LoadingOverlay 五角色弹跳动画，不重做另一套。黑屏至少2.4秒且旧结算场景在黑幕下释放、主页异步加载并完成绘制，五角色完整退场后用1.4秒渐亮揭开主页；不会换场时闪出一帧亮底。该链路已接独立结算预览的结尾，正式登顶入口仍待预览确认。

新增验证：tests/settlement_ghost_flight.gd（四向飞行、四角限位、惯性、帧率一致、光环不穿头、退场唯一信号）；tests/settlement_return_home.gd（纯黑、五角色复用、主页就绪后渐亮、遮罩清零）。

## 下移时重复上帝修复

光环动画用的 god_room 与结算长图顶部存在487像素竖向差异。原先只覆盖前1080像素，导致继续下移时露出长图中的另一份上帝，云前景也采到了同一残影。顶部背景现在与光环动画共用 god_room；1080以下跳过长图中对应的上帝，在云区连续接回2048切片边界。云前景同步使用相同的取图修正，后续结算框/数字坐标不变。原画文件未改。

返回主页改为黑幕完全盖住后先卸载旧结算场景，等待释放两帧，再异步载入主页；五角色和黑幕挂在树根跨场景保留。避免结算大图与主页引用的完整地图同时常驻造成纹理缺失。原生绘制检查 tests/settlement_opening_background.gd 验证原上帝存在、下方无重复黑描边、云背景不缺图及穿云完全遮挡；返回主页继续检查实际视口像素。

## 主键盘7快速查看结尾

运行游戏后按7，直接重载正式地图并在天空顶部触发原穿云动画，不需要先飞完天空。幽灵弹出后按当前构图、位置和速度连续接本结尾预览，中途没有黑幕，试玩橘子数量固定100，播放完整光环奖励和结算，最后返回主页。使用按键前本局的死亡次数与回放快照；从首页开始则没有实际游玩录像，框保持空白、次数为0。1～6正常入口不变，7可重播，切换其他入口会取消尚未完成的结尾交接。7仅供调试预览，不改正常关卡的收集数量或自动登顶规则。

7键入口不再使用淡黑换场。穿云期间预备资源；幽灵弹出后接住同一屏幕位置、速度与1.4倍比例，并按两张原画487像素的注册差保留当前构图，同一帧切到结尾。授环动画只控制上帝与光环，不再重置玩家位置；玩家可左右走动及跳跃，光环追踪当前头顶。回顾前，结尾角色先落稳，脚下打开原出云所用的CloudRipple褶皱，身体与光环逐渐通过云面裁切沉下去，褶皱收拢后再启动原下移时间轴。回顾阶段保留四向飞行，最终飞出/五角色黑幕/主页流程不变。
