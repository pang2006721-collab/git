# 天空冰雹危险长按提醒

按“冰雹快砸到，横向飞行来不及躲”实现，不将80理解为热量百分比。SkyShiftReminder读取现有冰雹位置、半径、下降速度、重力及鸟的速度，预测0.12～1秒内碰撞，再用保守反应时间和横向加速度/速度上限估算脱离距离。即使乐观可达距离仍不足时才提示。热量须达到既有minimum_charge（当前满热），不改燃烧/融冰规则。

复用头顶惯性跟随和每3秒长按图示。危险触发后短暂保留0.9秒避免提示闪烁；实际长按燃烧时持续压下，危险消退后淡出。融化中的冰雹、命中过的碎片、可避让/远处冰雹、热量不足、死亡和切关不触发。原天空局内录像与6键强制录像移除，主页说明书仍保留天空演示。

验证：原生ANGLE与无窗口临近碰撞、远离/横向安全、满热/80%热量、实际燃烧长按、切角色、6键无弹窗检查通过；既有燃烧融冰检查通过；四章主页录像首帧检查通过。此提示为预测引导，不锁住玩家或保证每次都能挽救。
