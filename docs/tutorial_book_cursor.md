# 说明书与鼠标

首页右上角说明书展示四段现有教程。恶魔、小鱼、松鼠、小鸟四个小豆子用于选页；当前页放大提亮。翻页箭头靠近画框，在首尾页回弹消失，返回可用页时重新弹出。每页播放完循环，关闭恢复首页状态。

`watched/<stage>` 只记录完整看过；`level_entered/<stage>` 独立记录关内首次教程结束或关闭。主页看过不会跳过第一次实际进关的教程，分段快捷键仍可反复重看。测试配置与真实存档分开。

鼠标使用用户原图，向直立方向修正15度。单个最高层软件光标持续绘制，取消点击期间逐帧更换系统光标，避免闪烁。点击时以图案中心压缩回弹，不移动实际点击位置；暂停、快速连点和跨场景均共用同一个节点。

主键盘7预览100橘子光环结尾，8预览未满100橘子的问答结尾（仅预览覆盖为0）。两者共用正式穿云及结尾入口，保留原自由移动、回顾与回首页流程，不修改正常游玩的橘子数。

验证：原生鼠标中心回弹、四页说明书完整交互/循环/关闭；四关首次进入记录；7/8实际按键切场景与取消；未满100结尾表情、自由移动与钻云回顾；四关视频/画框同步显现。

正式游玩鼠标显示规则：地狱正式场景（含海底、丛林、天空）及结尾中，初始静止隐藏；收到真实移动后0.24秒回弹出现，连续移动不反复触发。停止移动0.9秒后用0.12秒淡出；点击本身不唤醒隐藏鼠标，显示期间继续保持中心点击回弹。首页、暂停教程及死亡按钮阶段保持可见。跨场景重设闲置状态，仍复用同一软件光标，不反复更换系统图片。原生检查覆盖隐藏、移动出现/收稳、闲置消失、点击不唤醒、暂停/死亡可点及回首页显示。
