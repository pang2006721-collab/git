# 未满100橘子的求情动作

上帝在3.3秒开始低头，3.65秒闭眼完成，3.7～4.5秒摇头，随后抬头睁眼；对勾仍在4.7秒弹出。着色器只在头部局部柔和变形，过渡边界平滑，不改原图，100橘子的光环时间轴不变。

三个对话框有小幅连续水平/垂直漂动和轻微转动。求情框以幽灵头顶附近为锚点，水平距离由145减到112，保留头顶间距避免盖住表情。跟随使用解析临界阻尼弹簧，移动时滞后、停下后追上，并随速度轻微倾斜；跳转时间轴时直接复位，不从旧位置飞过来。所有动作只影响表现，小幽灵仍自由移动。

原生ANGLE及无窗口检查覆盖：低头闭眼摇头先于对勾、求情框位置/惯性/收稳、恢复姿态、100橘子光环分支，以及表情完成后钻云进入回顾。
